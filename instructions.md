Projects in the NUKS course

- Basic information

In the NUKS course, you will have to create a cloud native application during the semester. The project topics are arbitrary, if you do not know what project to choose, you can make a copy of existing services (Youtube, Spotify, etc.). You will work on the projects in pairs (or independently if you wish) and you will defend them during the last term of laboratory exercises. The projects will be divided into milestones, which will be checked on an ongoing basis.

Milestone 1: 9.4

- Your project idea must be ready
- You must draw a sketch of your application architecture

Milestone 2: 23.4

- You must have API calls made for your application
- You must have a microservices segmentation plan

Milestone 3: 7.5

- Your application must have implemented microservices
- Docker compose must be ready

Milestone 4: 21.5

- Your application must collect log information
- CI/CD pipeline implemented

- Technical requirements of the application

- The project must be published on a Git repository
- The application must have a frontend and a backend (the quality of the frontend depends on the type of application (data display vs webapp))
- The application must be composed of microservices and use docker compose
- You must use at least 1 relational and 1 non-relational database
- Use an API gateway or proxy
- Centralized logging (Grafana, Prometheus, ELK)
- CI/CD pipeline (only a static website is possible)
- Cloudflare account (we will provide you with the domains)
- Using S3 API (we provide a min.io instance)
